# QuizBattle --- STEP 3：クイズ問題データ設計・作成指示書（Unity AI向け）

## 目的

QuizBattleのクイズ問題を、ゲームロジックに直接書き込まずUnity
Editor上で編集・管理できるデータとして作成する。

今回は**問題データの仕組みのみ**を実装する。クイズ画面の表示、回答処理、タイマー、スコア計算、通信機能は対象外。

## 作業前の確認

-   既存のUnityプロジェクトとフォルダ構成を確認する。
-   STEP 1・STEP
    2の成果物を保持する。既存ファイルやシーンを削除・作り直さない。
-   `Assets/_Project/Scripts/Quiz` と `Assets/_Project/Data`
    を利用する（実際のフォルダ名が異なる場合は既存構成に合わせる）。
-   同名のクラスやファイルが既に存在する場合は、内容を確認して重複作成しない。

## データ設計方針

問題はUnityのScriptableObjectで管理する。Inspectorから問題文・選択肢・正解・ジャンル等を編集できるようにする。

### 1. QuizQuestion（1問分のデータ）

作成ファイル： `Assets/_Project/Scripts/Quiz/QuizQuestion.cs`

ScriptableObjectとして、以下の情報を持つ。

  フィールド           型           説明
  -------------------- ------------ --------------------------------
  questionId           string       問題を識別するID。例 `Q001`
  questionText         string       問題文
  choices              string\[\]   4つの選択肢
  correctAnswerIndex   int          正解の選択肢番号（0〜3）
  category             string       ジャンル名
  difficulty           enum         難易度（Easy / Normal / Hard）
  explanation          string       正解解説（任意）

要件: - `choices` は常に4個を基本とする。 - `correctAnswerIndex`
は0〜3で扱う（0が選択肢1、3が選択肢4）。 -
Inspectorでデータを編集できるようにSerializeField等を適切に使う。 -
ゲーム側からデータを読み取るための安全なGetterを用意する。不要な外部書き換えは防ぐ。 -
`CreateAssetMenu`
を設定し、Projectウィンドウから問題アセットを作成できるようにする。 -
Unityの標準機能のみを使い、追加パッケージは導入しない。 -
フィールド名・クラス名は英語、コメントは簡潔な日本語にする。

### 2. QuizQuestionSet（問題セット）

作成ファイル： `Assets/_Project/Scripts/Quiz/QuizQuestionSet.cs`

複数のQuizQuestionをまとめて保持するScriptableObject。

  フィールド    型                                               説明
  ------------- ------------------------------------------------ -----------------------------
  setId         string                                           問題セット識別ID
  displayName   string                                           Inspectorや管理用のセット名
  questions     QuizQuestion\[\] / List`<QuizQuestion>`{=html}   出題候補一覧

要件: - `CreateAssetMenu`
から問題セットアセットを作成できるようにする。 -
問題一覧をInspectorで登録・編集できる。 -
問題数を取得できる読み取り用プロパティを用意する。 -
空の要素やnull参照を安全に扱えるようにする。 -
問題の抽出やランダム出題ロジックは今回実装しない（次の工程で扱う）。

## データ検証

Editorで値を編集したとき、可能な範囲で `OnValidate()`
を使って入力内容を検証する。

-   問題IDが空の場合は警告
-   問題文が空の場合は警告
-   選択肢が4個ではない場合は警告（勝手に選択肢を増減して内容を壊さず、修正を促す）
-   選択肢に空欄がある場合は警告
-   正解番号が0〜3の範囲外なら警告
-   問題セット内にnull要素がある場合は警告
-   問題セット内に同一IDが複数ある場合は警告（可能なら）
-   警告は編集時の支援とし、データを勝手に削除・書き換えない

## データ保存場所

問題アセットと問題セットアセットを以下に保存する。

`Assets/_Project/Data/QuizQuestions/` `Assets/_Project/Data/QuizSets/`

フォルダがなければ作成する。ただし既存のフォルダ名・構成が異なる場合は既存構成に合わせて、重複したフォルダを作らない。

## サンプル問題

実装後、動作確認用に一般常識の4択問題を5問作成する。各問題は正解が1つだけで、解説も付ける。日本語で内容が正確で、誤解を招く曖昧な設問は避ける。

### Q001

問題: 日本の首都として一般に知られている都市はどこ？ 選択肢: 大阪 / 東京
/ 名古屋 / 福岡 正解: 東京（choices index 1） ジャンル: 地理 難易度:
Easy 解説: 東京は日本の首都として一般に知られています。

### Q002

問題: 水が標準的な大気圧で沸騰する温度は何℃？ 選択肢: 50℃ / 75℃ / 100℃ /
150℃ 正解: 100℃（choices index 2） ジャンル: 科学 難易度: Easy 解説:
標準的な大気圧では水の沸点は約100℃です。

### Q003

問題: 1年が通常何か月で構成される？ 選択肢: 10か月 / 11か月 / 12か月 /
13か月 正解: 12か月（choices index 2） ジャンル: 一般常識 難易度: Easy
解説: 1年は通常12か月です。

### Q004

問題: 太陽系で太陽に最も近い惑星はどれ？ 選択肢: 金星 / 地球 / 火星 /
水星 正解: 水星（choices index 3） ジャンル: 天文 難易度: Easy 解説:
水星は太陽に最も近い惑星です。

### Q005

問題: 日本の硬貨で、現在一般的に流通している額面として存在するのはどれ？
選択肢: 7円 / 25円 / 50円 / 200円 正解: 50円（choices index 2）
ジャンル: 一般常識 難易度: Easy 解説:
50円硬貨は現在流通している日本の硬貨です。

## 問題セットアセット

上記5問をまとめた `QuizQuestionSet` アセットを1つ作成する。 - setId:
`SET001` - displayName: `基本問題セット` - questions:
Q001〜Q005の5問を登録
