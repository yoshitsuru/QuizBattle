# QuizBattle STEP12 — オンライン2人対戦総合テスト・仕上げ

## 前提
STEP7〜11の機能を統合し、既存Soloモードを保持する。

## 目標
別々のUnity実行環境で2人がルーム参加→出題→回答→得点→結果→再戦/退出まで完走できることを検証する。

## 実装・検証指示
1. Unity Editor + Standalone Build、可能なら別PC同士でもテストする。単一Editorの擬似テストだけでオンライン成功と判断しない。
2. Photon App ID、Fusion 2.1.4、シーン登録、ネットワークPrefab、NetworkRunner寿命を確認する。秘密情報は報告に記載しない。
3. 正常系：部屋作成→参加→2人揃う→開始→同一問題・タイマー→回答→スコア→勝敗→再戦→退出。
4. 境界系：3人目参加、無回答、同時回答、時間切れ直前回答、連打、同点、問題セット不一致。
5. 障害系：Host切断、Client切断、接続失敗、連続再接続、再戦待機中の退出。
6. 画面系：1920×1080、1280×720、可能なら異なる縦横比、日本語フォント、長い問題文、ボタン操作を確認する。
7. 回帰：Soloモードで5問を完走し、得点・時間切れ・タイトル復帰が正しいことを確認する。
8. 見つかった不具合は再現条件・期待結果・実際結果・修正内容・再テスト結果を記録する。
9. 既存成果物を不用意に全面書き換えず、必要最小限の修正を行う。

## 完了基準
- [ ] 2つの実行環境で接続できる
- [ ] 両者で問題・タイマー・得点・結果が一致
- [ ] 二重回答・遅延回答が拒否される
- [ ] 退出・切断時に安全に復帰できる
- [ ] 再戦が動作する
- [ ] Soloモードが正常
- [ ] コンパイル・実行エラーなし

## 完了報告
テスト環境、実施項目、結果、ログの要約、修正一覧、残る不具合、未実施項目を明示する。未実施テストを合格扱いにしない。
